1. Hesap Bağlama Akışı (OAuth)

Kullanıcı bir platformu (önce YouTube ve Instagram) hesabına bağladığında sistemin izlediği yol:

sequenceDiagram participant K as Kullanıcı participant D as Dashboard (Web) participant B as Backend (FastAPI) participant P as Platform (Google / Meta) K->>D: "Instagram/YouTube bağla" butonuna tıklar D->>B: /connect/{platform} isteği B->>P: OAuth yetkilendirme sayfasına yönlendirir P->>K: Kullanıcıdan izin ister K->>P: İzin verir P->>B: /callback?code=... ile geri döner B->>P: code'u access_token + refresh_token ile değiştirir B->>B: Token'ları şifreli olarak veritabanına kaydeder B->>D: "Bağlandı" durumunu gösterir
Instagram için hesabın Business/Creator türünde ve bir Facebook Sayfasına bağlı olması gerekiyor. YouTube'da temel istatistikler için OAuth'a bile gerek yok — API key yeterli (aşağıda açıklanıyor).

6. Neden YouTube'dan Başlıyoruz

YouTube Data API v3, herkese açık video istatistiklerini (beğeni, yorum, izlenme sayısı) sadece bir API key ile veriyor — OAuth veya hesap onayı gerekmiyor. Bu yüzden bugün, hiçbir onay süreci beklemeden ilk çalışan entegrasyonu bitirebiliriz. Instagram tarafı Meta'nın uygulama incelemesini gerektirdiği için o iskelet hazır olacak ama gerçek veri çekimi onay geldikten sonra test edilebilecek.
